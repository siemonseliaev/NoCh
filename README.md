# CLI-приложение для анализа зависимостей (Этап 5: Визуализация)

## Описание проекта (Этап 5)
1. Формирует текстовое представление графа зависимостей на языке диаграмм **D2**.
2. Сохраняет визуализацию графа в файл формата **SVG** (через утилиту D2 или встроенный генератор разметки).
3. Поддерживает настройку пути сохранения через параметр `output_image` в конфигурационном файле `config.toml`.
