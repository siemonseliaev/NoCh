# CLI-приложение для анализа зависимостей (Этап 3: Построение графа зависимостей)

Минимальное CLI-приложение на Python (версии 3.11 и выше), предназначенное для построения транзитивного графа зависимостей пакетного менеджера **Cargo** (экосистема Rust) и тестовых репозиториев[cite: 6].

## Описание проекта

На данном этапе реализации приложение выполняет следующие задачи:
1. Строит полный транзитивный граф зависимостей анализируемого пакета[cite: 6].
2. Реализует обход графа с помощью **нерекурсивного алгоритма DFS** (с использованием явного стека)[cite: 6].
3. Учитывает максимальную глубину анализа (`max_depth`), заданную пользователем[cite: 6].
4. Корректно обнаруживает и обрабатывает **циклические зависимости**[cite: 6].
5. Поддерживает тестовый режим (`repo_mode = "test"`), позволяя загружать структуру графа из локального JSON-файла (`test_graph.json`), где пакеты обозначены заглавными латинскими буквами[cite: 6].

---

## Настраиваемые параметры (`config.toml`)

| Параметр | Тип | Описание | Пример значения |
| :--- | :--- | :--- | :--- |
| **`package_name`** | `str` | Имя пакета или путь к JSON-файлу графа | `"test_graph.json"`[cite: 29] |
| **`repo_url`** | `str` | URL-адрес репозитория или заглушка | `"https://github.com/example/repo"`[cite: 29] |
| **`repo_mode`** | `str` | Режим работы (`"online"`, `"offline"`, `"test"`) | `"test"`[cite: 29] |
| **`package_version`** | `str` | Версия анализируемого пакета | `"1.0.2000"`[cite: 29] |
| **`output_image`** | `str` | Путь к итоговому файлу изображения | `"output.png"`[cite: 29] |
| **`max_depth`** | `int` | Максимальная глубина анализа графа | `3`[cite: 29] |

---

## Архитектура модуля

* **`load_config(file_path)`** — загрузка и парсинг TOML-конфигурации.
* **`validate_config(config)`** — проверка типов данных и ограничений параметров.
* **`fetch_test_graph_data(file_path)`** — загрузка структуры тестового графа из JSON.
* **`build_dependency_graph_dfs(...)`** — нерекурсивный обход в глубину (DFS) с обработкой циклов и ограничением глубины.
