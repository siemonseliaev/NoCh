# CLI-приложение для анализа зависимостей (Этап 4: Дополнительные операции)

Минимальное CLI-приложение на Python (версии 3.11 и выше), предназначенное для анализа и вывода **обратных зависимостей** пакетов экосистемы Cargo (Rust) и тестовых графов[cite: 6].

## Описание проекта (Этап 4)

На данном этапе реализации приложение расширяет функциональность поиска и анализа графа[cite: 6]:
1. Выполняет инверсию построенного транзитивного графа зависимостей (алгоритм обхода из предыдущего этапа)[cite: 6].
2. Определяет **обратные зависимости** для заданного пакета (`reverse_target`) — список всех пакетов, которые зависят от указанного[cite: 6].
3. Добавляет новый обязательный параметр `reverse_target` в конфигурационный файл `config.toml` и проводит его валидацию[cite: 6].
4. Выводит полный граф обратных зависимостей в консоль для демонстрации связей между компонентами[cite: 6].

---

## Обновленная таблица параметров (`config.toml`)

К существующим параметрам конфигурации добавляется поле **`reverse_target`**:

| Параметр | Тип | Описание | Пример значения |
| :--- | :--- | :--- | :--- |
| **`package_name`** | `str` | Имя анализируемого пакета или путь к test-файлу | `"test_graph.json"`[cite: 36] |
| **`repo_url`** | `str` | URL-адрес репозитория или локальный путь | `"https://github.com/example/repo"`[cite: 36] |
| **`repo_mode`** | `str` | Режим работы (`"online"`, `"offline"`, `"test"`) | `"test"`[cite: 36] |
| **`package_version`** | `str` | Версия анализируемого пакета | `"1.0.2000"`[cite: 36] |
| **`output_image`** | `str` | Путь к итоговому изображению | `"output.png"`[cite: 36] |
| **`max_depth`** | `int` | Максимальная глубина анализа | `3`[cite: 36] |
| **`reverse_target`** | `str` | **Пакет для поиска обратных зависимостей** | `"B"`[cite: 36] |

---

## Архитектура дополнительных операций

* **`get_reverse_dependencies(graph, root_pkg)`** — принимает прямой граф зависимостей и перестраивает его в инвертированный граф вида `узел -> [пакеты, зависящие от него]`[cite: 6].
* **`run_stage_four(...)`** — модуль, отвечающий за поиск зависимостей для целевого пакета `reverse_target` и вывод обратного графа[cite: 6].
